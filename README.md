# Study-Session-Tracker---SE-2070
Description:
A study session tracker that can be utilized for anyone who would like to keep track of their study sessions and improve their productivity. The user is able to start the session, enter the subject they would like to study, and their desired study goal in minutes. Soon after the timer will immediately start, the app will track the users time as well as allow for pausing and resuming the session. Each session is saved after it ends and the user is able to view previous study logs located in the main menu. 

Features:
- timer that track study time
- the ability to pause and resume
- End Session
- View previous logs
- ability to know if your study session goal was met
- Reset current session
- Clear study logs
- Display total miinutes studied




How to run: 

You first compile the program by entering javac StudyTrackerApp.java in terminal then run it by entering java StudyTrackerApp
